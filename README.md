# 🚀 Путь Степана: Взаимодействие контейнеров (ДЗ 7)

Учебный проект в рамках сквозного кейса курса **«Путь Степана: от прототипа к проекту»**.  
Цель данного домашнего задания: перевести прототип веб-приложения в production-ready состояние, настроив взаимодействие между контейнерами с помощью Docker Compose.

## 🛠 Технологический стек

- **Язык**: Python 3.10
- **Фреймворк**: Flask + Flask-SQLAlchemy
- **База данных**: PostgreSQL 15 (Alpine)
- **Веб-сервер (Reverse Proxy)**: Nginx
- **WSGI-сервер**: Gunicorn (3 worker'а)
- **Контейнеризация**: Docker & Docker Compose

## ✨ Функциональность

1. **Главная страница (`/`)**: отображает список всех созданных задач, отсортированных по дате создания (новые сверху).
2. **Страница создания (`/create`)**: форма для добавления новой задачи (название и описание).
3. **Персистентность данных**: данные сохраняются в PostgreSQL и не теряются при перезапуске контейнеров благодаря Docker Volume (`postgres_data`).

## 🚀 Как запустить проект

### Требования

- Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/).
- Запущенный Docker Desktop.

### Пошаговый запуск

**1. Клонируйте репозиторий и перейдите в папку проекта:**

```bash
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
cd stepan-path-homework-7
```

**2. Соберите и запустите контейнеры в фоновом режиме:**

```bash
docker compose up --build -d
```

**3. Проверьте статус контейнеров:**

```bash
docker compose ps
```

Убедитесь, что все контейнеры запущены.

**4. Откройте приложение в браузере:**

Перейдите по адресу [http://localhost](http://localhost).

### 🛑 Остановка и очистка

**Остановить контейнеры (данные сохранятся):**

```bash
docker compose down
```

**Остановить контейнеры и удалить все данные базы данных (для чистого старта):**

```bash
docker compose down -v
```

> ⚠️ **Внимание!** Команда `docker compose down -v` удаляет Docker Volumes, включая сохранённые данные PostgreSQL. Используйте её, только если хотите полностью очистить базу данных.
